# wallclock：这三处用墙钟是刻意的，不是疏漏
# ---------------------------------------------------------------------------

# Readout.Refresh：过期判定确实用墙钟，但**不能**改成单调时钟。
# LastUpdated 是使用方给的绝对时间戳，两个合法用法依赖这一点：
#   1. 展柜与文档里的 LastUpdated=DateTime.Now.AddYears(1) 表示「永不过期」；
#   2. 历史回放 / 归档场景要喂一个过去的时间戳。
# 单调时钟两者都做不到。真正的危险是「差值为负时被当成刚刚更新过」，
# 这一条已经单独处理：超前超过 1 秒即进 :unknownage，不再落到「新鲜」。
wallclock  src/Cobalt.Fluent/Controls/Hmi/Readout.cs  Refresh

# Readout.BuildStatusText：算「最后更新 n 秒前」这行显示文字，不是超时判定。
# 判定已经在 Refresh 里做完并传进来了。
wallclock  src/Cobalt.Fluent/Controls/Hmi/Readout.cs  BuildStatusText

# DeviceStatusBar.OnApplyTemplate：把公开的 LastResponse（DateTime?，是对外
# API 的一部分，不能换成 ticks）在边界上转成时长交给 Heartbeat.Restore。
# 越过这个边界之后内部全程用 Environment.TickCount64。
wallclock  src/Cobalt.Fluent/Controls/Hmi/DeviceStatusBar.cs  OnApplyTemplate
